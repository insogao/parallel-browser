## 上传前验证

在 `codex/backlight-opencode` 隔离 worktree 中执行：

1. `pnpm -r --if-present run check`：通过。
2. `bash packages/tray/build.sh`：Backlight Tray.app 构建成功。
3. `pnpm --filter @backlight/daemon test`：退出码 0；25/25 单元测试通过，品牌资源测试通过，spike、supervisor、extensions、agent、background、usability 六组集成测试通过。
4. 六组集成日志均输出 `[Backlight acceptance]`，实际路径为临时目录中的 `Backlight.app`，可执行文件 SHA256 一致。
5. 捕获目标约 60fps，截图约 54–72ms；双窗口同扩展侧栏连续 3/3 未串窗；三页最小化后仍持续网络轮询。
